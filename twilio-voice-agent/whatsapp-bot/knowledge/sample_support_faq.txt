dcVoice support — quick reference (POC knowledge base)

Hours: Monday–Saturday, 9:00–21:00 (example).

Billing: Users can view invoices in the account portal. Refunds follow the standard policy; escalate to a human for disputed charges.

Technical issues: Ask the user to restart the app, check network, and update to the latest version. If it persists, collect device type and error message and escalate.

Courses and access: After purchase, access appears within a few minutes. If not visible, verify the logged-in account matches the purchase email.

Language: Support replies in the same language the customer uses when possible.
